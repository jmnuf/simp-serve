# Simp Serve

Simple & basic static server that serves files from a directory and is meant for local/personal usage, not production.
Made for viewing local files and downloaded documentation without running an interpreter.

Also this was made with no AI usage, pure hand coded effort cause coding is fun.

## Usage

**Requirement:**
- C compiler (`cc`, `gcc`, `clang`)
- Linux
- Sanity *(optional)*

Project uses [nob.h](https://github.com/tsoding/nob.h) build system.
Bootstrap the build system to build and run the program.
```sh
cc -o nob nob.c
./nob -O run example
```
